### Моки / сообщения на НТ

| Шаг | Что на НТ |
|---|---|
| Получение данных по заявке | Реальный/стендовый вызов facade (по аналогии с другими процессами) |
| Установить холд | **Мок** → SUCCESS |
| Создать платежное поручение | **Мок** → SUCCESS |
| Получить сообщение о завершении оплаты | **Подкладываем** сообщение в Kafka (сейчас вручную / как договоримся с НТ). В проде источник — внешний сервис EQ |

### Негативные кейсы

| Кейс | Статус для НТ |
|---|---|
| 4xx / 5xx EQ | Пока **не обязательны** — EQ mock-only |
| Timeout / no message | Есть timer **P5M**; моделировать при необходимости |
| Битый payload | Пока **не описан** как обязательный |

### Сценарии НТ

1. **Success (основной)**: get data → mock hold → mock create payment → подложить payment-finished → end `SUCCESS`.
2. **Timeout**: не публиковать payment-finished → timer 5 мин → reject по схеме процесса.
3. **Нагрузка**: считать от 15000/мес минус доля signing-timeout.
