### Моки / сообщения на НТ

| Шаг | Что на НТ |
|---|---|
| Получение данных по заявке | Facade (по аналогии с другими процессами) |
| Установить холд | Мок → SUCCESS |
| Создать платежное поручение | Мок → SUCCESS |
| Получить сообщение о завершении оплаты | Подкладываем в Kafka (вручную / как договоримся с НТ). В проде — EQ |

### Негативные кейсы

| Кейс | Статус для НТ |
|---|---|
| 4xx / 5xx EQ | Пока не обязательны (EQ mock-only) |
| Timeout / no message | Есть timer P5M; моделировать при необходимости |
| Битый payload | Пока не описан как обязательный |

### Сценарии НТ

| # | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Success (основной) | get data → mock hold → mock create payment → подложить payment-finished → `SUCCESS` |
| 2 | Timeout | не публиковать payment-finished → timer 5 мин → reject |
| 3 | Нагрузка | от 15000/мес минус доля signing-timeout |
