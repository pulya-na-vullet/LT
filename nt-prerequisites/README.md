## Общий профиль нагрузки (база)

- **15000 заявок / месяц** (канал SFA, рабочие часы ЮЛ).
- Оценка: ~21 рабочий день × 8 часов → **~89 заявок/час** в среднем.
- Пик (оценка ×2): **~180 заявок/час**.
- Таймаут-ветки: **~5%** от всех заявок (~750/мес, ~4–5/час).
- Из таймаутов: **~95%** — таймаут подписания; остальное — оплата / аварийный таймер main.
