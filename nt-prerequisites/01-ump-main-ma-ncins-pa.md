### Сценарии НТ

1. **Happy-path E2E** (~95%): start → prepare → stage DOCS_COMPLETED → signing → stage SIGN_COMPLETED → payment → stage PAYMENT_COMPLETED → finalisation → stage COMPLETED → end `SUCCESS`.
2. **Signing timeout** (~4.75% от всех): нет completion message → timer 25 мин (на НТ сократить) → delete-documents → `BANK_REJECT`.
3. **Payment timeout** (малая доля): нет payment message → timer 5 мин → reject/cleanup по схеме процесса.
4. **Main emergency timeout** (~0): timer 30 мин со старта main → delete-documents → `BANK_REJECT`.
