### Ответ удаления (текущее понимание бэкенда)

```json
{
  "acDocuments": [
    { "status": "1" }
  ]
}
```

- Ошибка: передали **не UUID** документа.
- Точный перечень HTTP 2xx/4xx/5xx и семантика `status` — **TBD аналитика** (сейчас таска моковая в BPMN).

### Сценарии НТ

1. **Timeout signing → delete**: моделируем 5% поток (из них ~95% signing-timeout) → delete mock SUCCESS → `BANK_REJECT` на оркестраторе.
2. **Timeout payment → delete**: редкий кейс.
3. **Main emergency 30 мин → delete**: аварийный.
4. **Негатив (когда появится реальный AC)**: невалидный document id (не UUID); прочие 4xx/5xx — после появления контракта от аналитики.

### Важное ограничение для НТ

> Реальное удаление в AC 1.0 на НТ **сейчас недостижимо**: нет своей папки в AC, а документ должен быть создан в prepare-documents. Поэтому для текущего НТ-прогона — **мок удаления**. После появления AC-интеграции в квартале документ нужно обновить.
