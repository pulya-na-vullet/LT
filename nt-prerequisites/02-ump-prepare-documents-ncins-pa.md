### PUT /products/{id}

- Формально работает как **PUT** (обновляет запись продукта).
- По смыслу для процесса важно добавление поля **`contractLink`**.
- Если бы был PATCH — передавалось бы только `contractLink`.

### Параллелизм

| Параметр | Значение |
|---|---|
| Системный лимит потоков | **200** (ответ бэкенда) |

### Сценарии НТ

1. **Success**: get application → prepare reportData → generate+save AC → PUT product → `result=SUCCESS`.
2. **Ошибка get application**: 4xx → `getProcessParams=ERROR`; 5xx → 3 ретрая по 1 сек, затем инцидент.
3. **Ошибка генерации ПФ**: 400 / 500 — поведение по сценарию процесса (**уточнить у Жени полный список тел ошибок**).
4. **Пик**: параллельная генерация в рамках лимита 200 потоков и ЧПН ~180/час.
